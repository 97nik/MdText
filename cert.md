
## Ручное добавление или обновление существующих сертификатов и provision profile'ов

```sh
make update_certs
```

Распределите необходимые сертификаты и профили в соответствующие папки.  

> [!Важно]
> Обратите внимание: если сертификат новый, присвойте ему название, совпадающее с идентификатором этого сертификата, полученным из Apple Developer.

После вернуться в терминал нажать Enter, после запустить команду 

```sh
make dev_certs
```

В конце запустить команду 

```sh
make init
```
##  Ручная загрузка билда в AppStore

Установка версии приложения:

```sh
bundle exec fastlane run increment_version_number version_number:4.0.0
```

Установка номера билда:

```sh
bundle exec fastlane run increment_build_number build_number:17
```

Сборка и загрузка в AppStore:

```sh
bundle exec fastlane AppStoreRelease
```
